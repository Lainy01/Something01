Tinyone features

Tinyone ensures graphical editing, designing and Web page creating is availiable everywhere on the go. Regardless what device you are using: a Windows laptop, a Mac or even an Android phone, Tinyone is ready to provide excellent opportunities.

Fully Responsive

Our app does not have high demands for system resources! Therefore, you can navigate through interface smoothly. Enjoy creating elaborate projects without having to wait for your system to catch up with your actions.

Fully layered PSD

PSD stands for Photoshop Document, a file format that supports images with multiple layers and masks. Tinyone can open and format PSD files freely, which opens new possibilites for graphics editing. Process complex photos anywhere on the go!

Wide Customization

Tinyone features a fully customizable interface. Choose a theme, set of icons and toolbar elements for your liking. Additionally, you can modify icons internally through third-party apps, and revert them to default settings if anything goes wrong.

HTML5 & CSS3

Our features allow you to create modern Web pages! Just click 'Create HTML page', sketch your design in the document, and Composer will handle the rest. You can switch to HTML view and edit the code for extra features or save the page locally.

Email Templates

Create email templates for any occasion: from corporate messaging and CVS to formal greetings and party invitations. The designs are supported by mainstream mail clients (Outlook, Thunderbird) and website (Gmail, Yahoo, outlook.com)!
